## Global Constraints (every implementer brief repeats these)

- **Edit with the Edit tool, `Write` for a new file, or an anchored `sed -i`. Never rewrite a whole existing file with a script**, except the one split script of Task 1, which asserts the size of every file it writes (each new file under 80 KB, the sum within 5 percent of the old README minus what is deliberately dropped). After any scripted edit run `git diff --stat` on that file and check the size (the W7i incident wrote 133 MB).
- `scripts/*.ps1` are ASCII with CRLF line ends and PowerShell 5.1 compatible: edit them with `sed -i` on single lines (the pattern never touches the final `\r`), then check `file scripts/update.ps1` still says "with CRLF line terminators" and `git diff --stat` shows only the lines meant.
- One commit per task, `git add` of NAMED files only, path-limited commits (`git commit -m ... -- <paths>`) when tasks run in parallel; trailer `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Implementers run only `uv run pytest <files>` (from `backend/`), `npx vitest run <files>`, `npm run typecheck`, git, grep, `bash -n`. No `docker`, no `scripts/*` execution.
- The ORIGINAL README is frozen at `.superpowers/sdd/2026-10-15-w10-docs/README.orig.md` (identical to `git show 50228b7:README.md`); every line range below refers to it. The merge table for the CHANGELOG is `.superpowers/sdd/2026-10-15-w10-docs/merges.txt` (`hash|date|subject`, newest first).
- **Tests are the contract.** A writer who rewrites a sentence a test pins keeps the pinned text (or moves it, never drops it). Writers do not edit test files; they report a conflict to the controller.
- **Docs style** (all pages): plain words for a data-centre engineer; a one-paragraph purpose first; ends with a "Related" line of links to neighbouring pages; relative links only; no per-wave history in a topic page (that is the CHANGELOG's job); no "W7x added" phrasing in topic pages; commands in fenced blocks; each fact once (link instead of repeating); the largest page stays under about 60 KB; do not introduce characters the old text avoided in commands.
