# w12c Discovery visual polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Discovery gets one regrouped toolbar, a shortcuts bubble, a clearer source card, icons on every node and in Find, a page icon, and a last-value card on mapped points.

**Architecture:** Front end first. Two small additive read-only backend changes feed the icons (asset `icon` and `kind_icon` on `GET /api/discovery/graph`) and the value card (`GET /api/mappings/{id}/latest`). The toolbar is one component (`GraphBar`) that now also holds Find, Snap, Refresh, Shortcuts and an overflow menu; its width tiers are CSS container queries. The bubble and the value card are standalone components that the page wires in.

**Tech Stack:** React 19, React Flow 12 (`@xyflow/react`), TanStack Query, vitest + Testing Library, Playwright (isolated scratch stack), FastAPI + SQLAlchemy + pytest.

**Spec:** `.waves/w12c.md` (the owner's words and the rulings C1 to C6). Roadmap row and backlog section are written at close-out.

**Tier: M** (a behaviour change across layers plus two additive, permission-gated reads; no migration, no new permission, nothing deleted). The plan review and the whole-wave review stay.

- NO new colour token (it would need all 21 presets). Use existing ones (`--ok --warn --crit --accent --accent-tint --border-strong --surface --text --text-2`).
- Every implementer brief says: "Edit files with the Edit tool or an anchored sed, never with a script that rewrites a whole file; after any scripted edit check the size and run `git diff --stat` on the file." CSS, `.tsx` and tests too.
- CSS: one `@layer w6` block per file; a class is named in ONE page file only (the clash guard in `app.css.test.ts`); before adding a selector grep `app.css` and `src/styles/*.css` for the same element; every selector names a class; no transition on node paints (a guard in `graph-nodes.css.test.ts`); every animation gets its own reduced-motion off switch. - Ages come from the server's clock (`age_seconds`), grown in the browser with `ageNow` (`lib/age.ts`), never the browser's clock against the server's.
- Accessible names: keep every name an existing test or e2e spec uses, or update every use (the A1 list below). Playwright matches by case-insensitive SUBSTRING: audit each new `aria-label`, heading or `<label>` against `getByLabel(` and `getByRole(` values in `frontend/e2e/*.ts`.
