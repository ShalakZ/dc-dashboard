2. **Crumb icons (T1).** `Crumb` gets an optional `icon?: IconName`; `Crumbs` draws `<span class="crumb-icon" aria-hidden="true"><Icon name=.../></span>` INSIDE the link or the current-page span, before the label, so a link's accessible name stays its text (an `aria-hidden` svg adds none) and `a.textContent` is unchanged. Size `1em` of the crumb font, `flex: none`, colour `currentColor`; the link/span becomes `display: inline-flex; align-items: center; gap: 5px; min-width: 0` and the label stays wrappable (`overflow-wrap: anywhere`), the row height must not change (measured). On the asset page: the first crumb uses `assets`, every ancestor and the current asset use `assetIcon(row)` (ancestors from the cached list; the current asset from the summary's own `data.asset`, as the page title does). `AssetKindsPage`'s first crumb ("Assets Tree") gets `assets` too, so the two trails that start with it agree; every other trail keeps text crumbs (Ruling 9b: the Dashboards, Sources and Audit trails have no per-row icon to show and a lone section icon would make the sidebar's job twice; cost if wrong: add `icon` to one more array). No skeleton change (the skeleton's trail is text-height lines; the icon adds width only).
3. **Layout rules (T5 pure code, T6 page).** Positions are decided in `buildGraph(model, open, { moved, ignoreSaved })`, which replaces the page's after-the-fact `moved.current.get(id) ?? position` override. A node's OWN place is `moved.get(id)`, else (unless `ignoreSaved`) `model.layout[id]`. A node without an own place stands at `its default + (its parent's actual - its parent's default)` where the parent is source -> cluster -> point, parent asset -> sub-asset (parents are placed first; a parent missing, a cycle or an orphan = no parent). `descendantNodeIds(model, id)` lists EVERY node under `id` in the model, open or not (`src:` -> its clusters `cluster:<sid>:<key>` and points `point:<id>`; `cluster:` -> its points; `asset:` -> all sub-assets by `parent_id`, cycle-safe; points and unidentified nodes -> none). **Drag (no Alt):** at drag start the page records the start place of the dragged nodes and of every VISIBLE descendant (from React Flow's own node list); on every `onNodeDrag` those followers are set to `start + (primary's current - primary's start)`; at drag stop the followers with an own place (session or saved) are moved by the same delta in `moved` and, with `discovery.edit`, sent in the SAME request as the dragged nodes together with the HIDDEN descendants that have a saved or session place (shifted by the delta); followers without an own place are NOT stored (they follow by the rule, and are where the drag left them). One request carries at most 2000 nodes (a longer list is sent as several consecutive requests; ids over 512 characters are skipped as today). **Alt (Option) held at drag start** = alone: no followers, nothing else shifts; Alt is read once at the start and holds for the whole drag. **Drop on an asset (maps):** the dragged node AND its followers go back to their start places, no layout is saved. Dragging a child never moves its parent. Cost if wrong: a child that was dragged away keeps its own absolute place and a later parent drag moves it by the delta, as the owner's "each keeping its offset" says.
4. **Tidy layout (T4 backend, T6 page).** New `DELETE /api/discovery/layout` (204, permission `discovery.edit`, removes every `graph_layout` row, idempotent, not audited like the PUT it mirrors). The existing PUT cannot restore the default for a node that is hidden (collapsed groups with an old absolute place would re-open far from their parent), so a front-end-only Tidy would leave the very bug the owner reported. The page: a **Tidy layout** button in the new bar. With `discovery.edit` it first asks "Tidy the layout for everyone?" (`useConfirm`, confirm label `Tidy layout`), then calls the route, clears `moved`, sets `tidied` (so `buildGraph` ignores `model.layout` until the page is left), waits for the graph to be read again and refits the view with the W7r opening rules (`initialView({ ...model, layout: {} })`). Without `discovery.edit` there is no question and no request: `moved` is cleared and `tidied` set (their own view only; a toast says so). A failed call leaves everything as it was and shows the server's reason (`role="alert"`). Cost if wrong: one more route; the owner asked for "the existing layout route", this does the same job completely.
5. **Summary line, Collapse all, Expand all (T5 + T6).** `graphSummary(model)` = `"3 sources, 120 points, 6 mapped, 1 needs credentials"`: sources and points always (`1 source, 1 point`), `N mapped` always (points with an asset, counted in the arrays the graph draws), `needs credentials` only when above 0 (`1 needs credentials`, `2 need credentials`). A bar `div.graph-bar` between the header and the canvas holds the summary (`<p aria-live="polite" aria-atomic="true">`, role-less, ONE announcer; React leaves the text node alone when the numbers do not change, so it speaks only on a change) and three buttons: **Collapse all**, **Expand all**, **Tidy layout**, always drawn (aria-disabled, never native `disabled`, when there is nothing to collapse or expand). `expandAll(model)` opens every source, then groups in model order while the groups' points stay within a budget of 600 NEW nodes (`EXPAND_NODE_BUDGET`); a group that would not fit stays closed and the page says so in a toast ("Opened every source. 4 groups stay closed: opening them would draw more than 600 nodes."). The view does not move (except Tidy). The loading branch draws a same-height empty bar (`.graph-bar-space`, `aria-hidden`).
6. **Scope form (T3).** `lib/ports.ts` (pure, table-tested): `PORT_NAMES = { 502: "Modbus", 4840: "OPC UA", 9000: "simulator", 5020: "Modbus (dev simulator)" }`, `portName(p)`, `portLabel(p)` = `4840 (OPC UA)` or `4080`, `portsLine(ports)` = the readout, `portHint(port, known)` = `{ port, near, text } | null`. The nearest wins (ties: the smaller port). Table: 4080 -> 4840, 4804 -> 4840 (swap), 4048 -> 4840, 484 -> 4840, 48400 -> 4840, 5022 -> 5020, 503 -> 502; NO warning for 502, 4840, 9000, 5020, 80, 443, 8080, 8443, 3306, 22, 65535, 1, 7, 12345.
